# Commands

This section is the reference for the `fm` CLI commands. Each page explains what the command does, how to use it, and gives examples.

| Command | What it does | Link |
|---|---|---|
| `create` | Create a new bench | [create](create.md) |
| `start` | Start a bench | [start](start.md) |
| `stop` | Stop a bench | [stop](stop.md) |
| `restart` | Restart bench services | [restart](restart.md) |
| `delete` | Delete a bench | [delete](delete.md) |
| `list` | Show all benches | [list](list.md) |
| `info` | Show bench details | [info](info.md) |
| `logs` | View bench logs | [logs](logs.md) |
| `shell` | Open shell / run commands | [shell](shell.md) |
| `code` | Open in VSCode | [code](code.md) |
| `update` | Update bench configuration | [update](update.md) |
| `reset` | Reset a bench (destructive) | [reset](reset.md) |
| `migrate` | Run fm migrations | [migrate](migrate.md) |
| `ngrok` | Create ngrok tunnel | [ngrok](ngrok.md) |
| `ssl` | Manage SSL certificates | [ssl](ssl.md) |
| `services` | Manage global services | [services](services.md) |
| `self` | Manage the tool itself | [self](self.md) |

For command details use `fm <command> --help` or read the individual pages listed here.
